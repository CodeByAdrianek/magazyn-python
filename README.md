# Magazyn Python

Prosty program do zarządzania magazynem napisany w Pythonie.

## Funkcje

- Wyświetlanie produktów z magazynu
- Wyszukiwanie produktów
- Dodawanie nowych produktów
- Generowanie raportów magazynowych

## Uruchomienie

1. Otwórz folder projektu w Visual Studio Code.
2. Otwórz terminal w folderze projektu.
3. Uruchom program poleceniem: \python 14.program.py``

## Technologie

- Python — język, w którym powstał magazyn
- Git i GitHub
- Poznajemy git fetch
